Reference data and external tools¶

Nothing is downloaded without a command. Methods that need missing data stop with refdata_missing (or backend_missing) and the exact command to run; downloads over 100 MB need --yes, so an agent has to ask you first. genor doctor shows what each missing piece blocks.

Reference datasets (genor refdata list | fetch | remove)¶

Name Size Build Ancestry Used by Source / licence

g1000-eas 323 MB GRCh37 EAS clumping Zenodo 10515792 (1000 Genomes, open)
chain-hg19-to-hg38 0.2 MB — — liftover UCSC
chain-hg38-to-hg19 1.2 MB — — liftover UCSC
pleiofdr-template 262 MB GRCh37 EUR condFDR/conjFDR precimed
pleiofdr-ref-eur 2.4 GB GRCh37 EUR condFDR/conjFDR precimed

Every entry has a pinned SHA-256 in src/genor/refdata/registry.toml; downloads that do not match are rejected. The pleioFDR files have no published checksum, so their pins are the hashes GeNor's maintainers saw on 2026-11-25. The SHA-256 seen is recorded in each run's manifest.
