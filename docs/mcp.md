# MCP tools

Generated by `scripts/gen_cli_docs.py`. Start the server with `genor mcp` (stdio). Analyses run as background jobs: tools wait up to `wait_seconds` (max 50, under Codex's 60 s default tool timeout) and otherwise return a `job_id` for `job_status` / `job_result`. Relative paths resolve against the workspace: `$GENOR_WORKDIR`, else the server's working directory (`~/genor-workspace` when that is `/`).

## `backend_add`(`name`, `path`)

Register a tool the user installed themselves (e.g. MAGMA, whose licence forbids bundling).
path is the executable (named as the registry expects, e.g. 'magma') or its directory.

## `backend_install`(`name`, `wait_seconds`?)

Download a pinned redistributable binary: plink2, gcta or smr.

## `backend_list`()

External tools (PLINK 2, GCTA, SMR, MAGMA, pleioFDR) and how to enable missing ones.

## `doctor`()

Platform, available backends, downloaded reference data, and what each missing piece blocks. Call first.

## `example_data`(`out_dir`?)

Copy the bundled simulated GWAS pair (BMI_sim exposure, MDD_sim outcome) into the workspace.

## `get_guidance`(`topic`?)

GeNor skill text for clients without skills support. topic: 'genor' (start here), a workflow such as
'mendelian-randomisation', or '<skill>/references/<file>.md'. No topic lists all topics.

## `job_cancel`(`job_id`)

Cancel a running job.

## `job_logs`(`job_id`, `n`?)

Last log lines of a job.

## `job_result`(`job_id`, `wait_seconds`?)

Result JSON of a finished job (optionally wait up to wait_seconds).

## `job_status`(`job_id`)

State of a background job: running, done, failed or cancelled.

## `list_methods`()

Methods accepted by run_analysis and their parameters.

## `list_runs`()

Run directories (with manifest.json) in the workspace.

## `lookup_enrichment`(`genes`, `background`?, `sources`?)

g:Profiler functional enrichment (GO, Reactome, KEGG, HPA) with g:SCS correction.

## `lookup_genes_in_region`(`region`, `build`?)

Genes overlapping chr:start-end (Ensembl), for positional mapping of loci.

## `lookup_open_targets`(`kind`, `query`, `n`?, `entity`?)

Open Targets Platform. kind: search (free text), target (Ensembl gene ID), disease (EFO/MONDO ID),
variant (GRCh38 CHR_POS_REF_ALT: credible sets + L2G), coloc (studyLocusId).

## `lookup_string`(`genes`, `required_score`?)

STRING v12 interactions among genes and PPI enrichment p-value.

## `lookup_variants`(`rsids`, `build`?)

Ensembl VEP: most severe consequence and genes for up to 200 rsIDs.

## `read_run`(`run_dir`)

Short result of a run directory (result.json) plus the list of files it wrote.

## `refdata_fetch`(`name`, `confirmed_by_user`?, `allow_unpinned`?, `wait_seconds`?)

Download a reference dataset. Datasets over 100 MB require the user's confirmation: ask them,
then call with confirmed_by_user=true. A dataset without a pinned checksum (none at present)
also needs allow_unpinned=true, again only after the user agrees.

## `refdata_list`()

Reference datasets (LD scores, 1000G panels, chain files), sizes, and whether downloaded.

## `report_build`(`run_dirs`, `out`?, `title`?)

Combine run directories into a Markdown + HTML report with warnings, decisions and citations.
out must be inside the workspace.

## `run_analysis`(`method`, `params`, `wait_seconds`?)

Run an analysis as a background job. method is one of:
sumstats.load, sumstats.liftover, meta, ldsc.h2, ldsc.rg, clump, mr, pleio, finemap.abf, coloc.abf, magma.gene, magma.sets.
params use the CLI option names with underscores (see list_methods). Returns the result if done within
wait_seconds, else a job_id to poll.

## `sumstats_load`(`file`, `trait`, `out`?, `build`?, `ancestry`?, `n`?, `n_cases`?, `n_controls`?, `population_prevalence`?, `effect_type`?, `columns`?, `maf`?, `info`?, `drop_mhc`?, `wait_seconds`?)

Load a user's summary statistics file: detect columns, standardise, infer build, QC, plots.
Returns the trait directory (pass it to other tools). Do not guess ancestry or N: ask the user.

## `sumstats_sources`(`name`?)

Where users can download GWAS summary statistics (GWAS Catalog, PGC, OpenGWAS, FinnGen, Pan-UKB, ...).
GeNor never downloads GWAS itself; the user downloads and gives a local path.

## `run_analysis` methods

| method | CLI | params |
|---|---|---|
| `sumstats.load` | `genor sumstats load` | file, trait, out, build, ancestry, n, n_cases, n_controls, population_prevalence, effect_type, columns{canonical:filecol}, maf, info, drop_mhc |
| `sumstats.liftover` | `genor sumstats liftover` | trait, to (GRCh37|GRCh38), out |
| `meta` | `genor meta run` | traits[list of trait dirs], scheme (ivw|samplesize), name, out |
| `ldsc.h2` | `genor ldsc h2` | trait, pop_prev, intercept, ref, w, out |
| `ldsc.rg` | `genor ldsc rg` | trait1, trait2, pop_prev1, pop_prev2, out |
| `clump` | `genor clump run` | trait, mode (plink|distance), preset (loci|mr), p1, r2, kb, panel, out |
| `mr` | `genor mr run` | exposure, outcome, p_threshold, clump_mode (plink|distance), panel, instruments, exclude_mhc, overlap (none|partial|substantial|unknown), nboot, seed, out |
| `pleio` | `genor pleio run` | trait1, trait2, stat (condfdr|conjfdr), fdr, randprune_n, seed, keep_mhc, prepare_only, ref_mat, template, out |
| `finemap.abf` | `genor finemap abf` | trait, region (chr:start-end) or lead, window_kb, p1, level, out |
| `coloc.abf` | `genor coloc abf` | trait1, trait2, region or lead, window_kb, p1, p2, p12, out |
| `magma.gene` | `genor magma gene` | trait, gene_loc, ref_bfile, up_kb, down_kb, out |
| `magma.sets` | `genor magma sets` | genes_raw, set_annot or covar, out |
