# Validation

Native reimplementations are the main correctness risk, so each is compared with the reference
tool on fixed inputs. Reference values are stored in `tests/golden/` and regenerated by scripts in
`scripts/golden/`.

| GeNor | Reference | Fixture | Agreement | Test |
|---|---|---|---|---|
| MR: IVW, IVW-FE, Egger, Wald, leave-one-out | TwoSampleMR 0.7.14 | 141 harmonised instruments | 1e-8 relative | `tests/test_golden.py` |
| MR: weighted median, weighted/simple mode (point) | TwoSampleMR 0.7.14 | same | 1e-6 relative | same |
| MR: bootstrap SEs | TwoSampleMR 0.7.14 | same | within Monte Carlo error (15–30%) | same |
| coloc ABF, finemap ABF | coloc 5.2.3 | 300-SNP simulated region | 1e-6 relative | same |
| Meta-analysis fixed/random, Q, I², τ² | R meta 9.0.0 (`metagen`, DL) | 3 studies × 60 variants | 1e-8 relative | same |
| LDSC h2, rg, SEs, intercepts | original `ldsc.py` (CBIIT/ldsc ldsc313 @ 128f996) | munged example traits | 1e-6 relative | `tests/test_ldsc_golden.py` (slow) |
| condFDR via pleioFDR port | pleioFDR port on original demo MAT files | chr21 demo, alleles re-encoded | identical tables | `scripts/golden/pleio_roundtrip.py` |

Regenerating:

```bash
Rscript scripts/golden/make_golden.R                 # needs TwoSampleMR, coloc, meta, jsonlite
python scripts/golden/ldsc_reference.py <ldsc checkout> <refdata dir>
python scripts/golden/pleio_roundtrip.py             # in a folder with the pleioFDR demo + template
```

## End-to-end check on simulated data

`genor example` ships data simulated from the real 1000G HapMap3 LD-score structure with known
parameters (`truth.json`). On it, LDSC rg is 0.142 ± 0.032 (truth 0.15), IVW MR 0.136 ± 0.018
(truth 0.15), weighted median 0.147 and weighted mode 0.152, and the three planted pleiotropic
instruments trigger the heterogeneity and Egger-intercept warnings.
`tests/test_pipeline.py` checks the MR estimate stays within 3 SE of the truth.

## Not validated yet

- PLINK clumping output is PLINK's; GeNor's part (per-chromosome runs, panel selection, guards)
  is covered by the example run, not a golden test.
- MAGMA wrapping has no automated test (MAGMA cannot be installed in CI).
- The release-gate agent test (Claude Code and Claude Desktop completing "estimate the genetic
  correlation and causal effect of BMI on depression" with the right stop-and-ask points) is a
  manual checklist before each release.
